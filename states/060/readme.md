В mlut есть и *custom states* - заготовки для частоиспользуемых комбинаций селекторов. Как и у большинства custom сущности, их названия в утилитах начинаются с `-`, например `-evc`. Полный их список также есть в [документации](https://docs.mlut.style/section-settings.html#kssref-settings-utils-config-states-custom).

А тем временем, мы перестраиваем область обложки и добавляем отступ для аватара. Это готовит компонент к интерактивности его дочерних кнопок.
