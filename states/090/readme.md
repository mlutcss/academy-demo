А теперь откроем главную тайну states! Дело в том, что states - это по сути, упрощенный [selector list](https://developer.mozilla.org/en-US/docs/Web/CSS/Selector_list) из CSS. То есть, в них вы можете использовать большую часть с возможностей селекторов CSS, следуя похожей логике. Только некоторые комбинаторы будет отличаться по синтаксису. В частности:

- `:` - объединение states (compound)
- `<empty>:` - пробел в селекторе

Также доступны множественные селекторы через `,`. На данном шаге мы попробуем их применить для `input` и `textarea`, чтобы задать цвет текста и `transition` этим элементам.
