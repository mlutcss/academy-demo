В этом уроке мы продолжаем осваивать методологию Atomic CSS, используя фреймворк [mlut](https://mlut.style/).

Ранее мы узнали, что утилиты в mlut состоят из *компонентов*. Сегодня начнем детально разбираться с одним из них, который называется *states*. Посмотрим, какие они бывают и для чего применяются.

Для демонстрации используется web-версия mlut, поэтому CSS будет автоматически генерироваться из разметки. Но из-за технических ограничений, в открытой вкладке со стилями показывается только заготовленный CSS.
