Завершаем форму состояниями `focus` и `focus-within`. Суффикс `_fw` реагирует на фокус внутри `label`, а `^:fw:` передаёт это состояние вложенной подписи или полю.

У обязательного поля добавляем псевдоэлемент через `_af`, а `Bdc-$accent400_!fw:h` меняет цвет рамки по наведению только пока поле не находится в фокусе. В результате получаем понятную интерактивную форму без отдельного CSS.
