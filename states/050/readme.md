Кнопки на обложке не должны отвлекать, пока пользователь не взаимодействует с областью изображения. Сначала скрываем их утилитой `O0`.

Затем именуем контекст `-Ctx-wallpaper` и используем `^wallpaper:h:_O1`: дочерний элемент получает непрозрачность `1`, когда курсор находится над родительской обложкой.
