В states мы можем использовать любые псевдоселекторы CSS и комбинировать их друг с другом, через разделитель `:`. Полный список сокращений для них можно посмотреть в [документации](https://docs.mlut.style/section-settings.html#kssref-settings-utils-config-states).

Завершаем верстку верхней панели и стилизуем кнопку закрытия модального окна. Здесь так же не забываем про состояние наведения на кнопку.
